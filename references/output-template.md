# Output template

Use these sections in order. Adapt depth and omissions to the user's scope.

1. **分析范围与素材参数** — URL/path, title, creator, duration, resolution, fps, evidence, timestamp tolerance.
2. **一句话视觉结论** — the editing mechanism that sustains visual attention.
3. **视觉结构总链路** — one compact arrow chain of visual states.
4. **分段画面逻辑拆解** — timestamp, visual task, composition, connection to adjacent segments, reusable technique.
5. **秒级画面与剪辑表** — timestamp, visible composition, motion/cut, caption treatment, sound/rhythm note, editorial purpose.
6. **镜头结构统计** — A-roll, full-screen cards, demos, screen recordings, PIP, hard-cut candidates, dense and breathing sections.
7. **字幕系统** — normal captions, emphasis captions, line/chunk rules, approximate parameters, platform safe areas.
8. **动效与视觉包装** — background, cards, PIP, screenshots, hierarchy, entry/exit order, estimated duration/easing.
9. **声音与节奏** — measured loudness when available, music role, silence, accent SFX recommendations; mark inference.
10. **文案/口播部分** — include only when requested; otherwise state that it is intentionally excluded.
11. **可直接套用的剪辑操作稿** — time-budget table and editor-ready instructions.
12. **NLE 轨道搭建** — picture, cards/B-roll, screenshots, PIP, emphasis text, captions, music, and SFX.
13. **复刻纪律与避坑** — copy structure and technique, not claims, wording, proprietary visuals, or data.
14. **最终公式** — one-line reusable visual-editing formula.

Minimum quality bar:

- Cover the full runtime without unexplained gaps.
- Include at least 10 timestamped visual beats for videos longer than 60 seconds.
- Tie every motion observation to visible evidence.
- Hand the operation script directly to an editor without requiring the analysis to be reread.
